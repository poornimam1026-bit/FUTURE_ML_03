# 📄 Resume Screening System

## 📌 Project Overview

This project is an **AI-powered Resume Screening System** that uses **Natural Language Processing (NLP)** and Machine Learning techniques to analyze resumes and match candidates with job requirements.

The system extracts skills from resumes, identifies missing skills, calculates a match score, and ranks candidates based on their relevance to the job requirements.

## 🎯 Objectives

* Analyze resume data
* Extract relevant skills and keywords
* Compare candidate skills with job requirements
* Identify missing skills
* Calculate candidate match scores
* Rank candidates based on their relevance
